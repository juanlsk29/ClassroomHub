# ClassroomHub

ClassroomHub es un pequeño portal web de recursos de aprendizaje desarrollado con Django. El proyecto permite navegar entre una página principal, una lista de recursos y una página informativa, utilizando URLs, vistas y plantillas HTML.

## Instalación

1. Crear y activar un entorno virtual.
2. Instalar las dependencias:


"python -m pip install -r requirements.txt"

## Tecnologías

- Python
- Django
- HTML
